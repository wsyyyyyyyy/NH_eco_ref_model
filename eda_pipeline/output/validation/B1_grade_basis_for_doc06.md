## 1. 리스크 등급 변환

### 1-1. 예측 확률 → 5등급 매핑

모델이 내놓는 것은 0~1 사이의 부도확률 한 개다. 현업이 쓰는 단위는 등급이므로 변환이
필요하다. **변환은 확률을 직접 자르지 않고 로그오즈를 표준화한 Z-Score 를 자른다.**

```
LOG_ODDS = ln( PD / (1 - PD) )
Z_SCORE  = (LOG_ODDS - mu) / sigma          mu = -4.1864,  sigma = 2.8373
```

| 등급 | Z-Score 구간 | 대응 PD 구간 | 성격 |
|---|---|---|---|
| **G1** | Z ≤ −1.0 | PD ≤ 0.089% | 정상 |
| **G2** | −1.0 < Z ≤ 0.0 | 0.089% < PD ≤ 1.497% | 정상 |
| **G3** | 0.0 < Z ≤ +1.0 | 1.497% < PD ≤ 20.603% | 주의요망 |
| **G4** | +1.0 < Z ≤ +2.0 | 20.603% < PD ≤ 81.582% | 고위험 |
| **G5** | Z > +2.0 | PD > 81.582% | 부실우려 |

> `mu`/`sigma` 는 **Valid 홀드아웃(202401~202505, 312,334행) 로그오즈의 평균/표준편차**다.
> 전 구간 분포로 표준화하면 홀드아웃 밖 정보가 컷오프에 들어가므로 Valid 로 고정했다.
> 컷오프 `[-1, 0, +1, +2]` 는 등폭 Z 이며 데이터를 보고 조정하지 않았다
> (`grade_mapping_v2.json` 의 `z_cutoffs_adjusted = false`).

**왜 확률을 직접 자르지 않는가.** 부도확률은 0 근처에 극단적으로 몰려 있어(전 구간
기저율 1.0350%) 확률 등분할은 하위 등급을 사실상 구분하지 못한다. 로그오즈는 이 왜곡을
펴 주므로 등폭 컷오프가 의미를 갖는다. 그리고 **로그오즈 변환은 순위를 바꾸지 않으므로
등급은 확률 보정 방식과 무관하다** — 이 점은 아래에서 실측으로 확인했다.

### 1-2. 등급별 실제 부도율

**Valid 홀드아웃 (202401~202505, 312,334행, 기저율 1.2254%)** — 성능을 말할 때의 정본

| 등급 | 관측치 | 부도건수 | 부도율% | Lift |
|---|--:|--:|--:|--:|
| G1 | 52,320 | 32 | 0.0612 | 0.05 |
| G2 | 98,552 | 206 | 0.2090 | 0.17 |
| G3 | 109,809 | 939 | 0.8551 | 0.70 |
| G4 | 47,793 | 1,939 | 4.0571 | 3.31 |
| **G5** | 3,860 | 716 | **18.5492** | **15.12** |

**단조성 확보.** 등급이 한 단계 나빠질 때마다 부도율이 예외 없이 올라간다.
**G5 는 전체 대비 15.12배**, 상위 1.24%(3,860 / 312,334)에 부도 716건이 몰려 있다.

**전 구간 (202101~202505, 948,214행, 기저율 1.0350%)** — 포털이 보여 주는 모집단

| 등급 | 관측치 | 점유율% | 부도건수 | 부도율% |
|---|--:|--:|--:|--:|
| G1 | 195,438 | 20.61 | 32 | 0.0164 |
| G2 | 313,583 | 33.07 | 207 | 0.0660 |
| G3 | 309,246 | 32.61 | 985 | 0.3185 |
| G4 | 116,157 | 12.25 | 2,392 | 2.0593 |
| **G5** | 13,790 | 1.45 | 6,198 | **44.9456** |

> ★ **같은 컷오프인데 G5 부도율이 18.55%(Valid) vs 44.95%(전 구간)로 다르다.**
> 모델이 달라진 것이 아니라 **집계 모집단이 다르다.** Train/Dev 구간(< 202301) 기저율은
> 0.7876%, Valid 구간(≥ 202301)은 1.2254% 이며, 전 구간 집계에는 학습에 쓰인 구간이
> 포함된다. **홀드아웃 성능을 주장하는 자리에서는 Valid 값(18.55%)만 쓴다.**
> 전 구간 값은 포털 화면에 보이는 분포를 설명할 때만 쓰고, 반드시 구간을 병기한다.

### 1-3. 등급은 확률 보정 방식과 무관하다 — 전수 검증

이 모델은 표시 목적에 따라 네 가지 확률을 산출한다 — `raw`, `prior`, `platt_train`,
`platt_dev` (근거와 선택 이유는 03 문서 및 `step36_final_config.md` §6). **이 중 어느
것을 쓰더라도 등급은 바뀌지 않는다.** Platt 보정 `sigma(a·logit(p) + b)` 는 `a > 0` 인
순증가 함수이고, Z-Score 표준화도 순증가 함수이므로 **개체별 순위가 보존**된다.

이론에 기대지 않고 전수로 확인했다 (`corporate_panel` 948,214행, 샘플 아님).

| 비교 쌍 | 순위 불일치 행수 |
|---|--:|
| `Z_SCORE` vs `PROB_RAW` | **0** |
| `Z_SCORE` vs `LOG_ODDS` | **0** |
| `PROB_RAW` vs `PROB_PLATT_TRAIN` | **0** |
| `PROB_RAW` vs `PROB_PLATT_DEV` | **0** |

**불일치 0건.** 따라서 보정 방식 선택은 **화면에 표시하는 PD 값**만 바꾸고,
등급 · 경보 대상 · AUC · Lift 는 전혀 건드리지 않는다.
포털은 확정 방침에 따라 **raw 확률(`PROB_FULL`)** 을 표시한다.

### 1-4. 5단계 등급과 16단계 표기 등급의 관계

포털은 등급을 두 가지로 보여 준다. **둘은 목적이 다른 별개 체계이며 서로 어긋나지 않는다.**

| | **5단계 (리스크 등급)** | **16단계 (표기 등급)** |
|---|---|---|
| 라벨 | G1 ~ G5 | AAA ~ CCC (NICE/KIS 표기) |
| 산출 기준 | 로그오즈 **Z-Score** 등폭 컷오프 | raw PD **분위** 컷오프 (40th ~ 99.6th) |
| 용도 | **리스크 판정** — 경보 대상(G4/G5) 선별, 집계 | **표기** — 기존 CB 등급과 눈높이 맞춤 |
| 부도율 단조성 | **확보** (Valid · 전 구간 모두) | 1쌍 역전 (`AA0` > `AA−`, 표본 노이즈) |

두 체계의 컷오프를 같은 축으로 환산하면 **하나의 정렬된 사다리**를 이룬다. 16단계 경계를
Z 로 환산한 값은 −0.2286 부터 +2.2634 까지 단조 증가하며, 5단계 경계(−1 / 0 / +1 / +2)
사이에 끼어든다. 전수 교차표에서도 **어떤 16단계 밴드도 비인접 5단계 등급을 걸치지 않는다.**

| 5단계 | 함께 나타나는 16단계 밴드 |
|---|---|
| G1 | AAA |
| G2 | AAA · AA+ |
| G3 | AA+ · AA0 · AA− · A+ · A0 · A− · BBB+ |
| G4 | BBB+ · BBB0 · BBB− · BB+ · BB0 · BB− · B+ |
| G5 | B+ · B0 · CCC |

> "Z 기준 G5 인데 16단계로는 중간 등급" 같은 사례는 **0건**이다.
> 16단계는 Z ∈ [−0.23, +2.26] 구간만 세분하므로 G1 전체와 G2 대부분이 `AAA` 한 밴드로
> 뭉친다. 저위험 구간을 잘게 나눌 실익이 없어 40th 분위에서 시작한 설계의 결과다.
>
> **리스크 판정 근거로는 5단계만 쓴다.** 16단계는 표기이며 부도율 단조성이 완전하지
> 않다(`AA0` 0.5977% > `AA−` 0.5550%, Valid — 각 23,425행에서 부도 140건 vs 130건의
> 표본 노이즈). 이 사실을 숨기지 않는다.
