# [Step 26] 전체 기업 수가 기준월과 무관하게 고정되는 원인 확인

> **작성일**: 2026-07-04
> **기준**: 사용자가 "메인화면 총 업체 수가 기간에 따라 달라지지 않는다"고 지적

---

## 1. 확인

`portal.duckdb`를 직접 조회해 2021.01~2026.06 전체 66개월의 `COUNT(DISTINCT V_BZNO)`를 비교한 결과, **26,184개사 전원이 66개월 내내 한 달도 빠짐없이 존재**함을 확인. 같은 기간 `고위험군(G4/G5)` 수는 2,339개(2021.12) → 4,539개(2024.02) → 6,752개(2025.02)로 실제로 변하고 있어, 등급 계산 로직 자체는 기준월별로 정상 작동 중임을 함께 확인.

즉 버그가 아니라 **패널 데이터가 처음부터 "균형 패널"(모든 회사가 전체 관측기간에 걸쳐 존재)로 구성**되어 있어서 총 기업 수가 구조적으로 고정된 것. `COPR_OPNP_C`(기업공개코드) 필드도 확인했으나 월별로 변하는 "이번 달 영업 여부" 플래그가 아니라 회사별 고정 속성 코드였음(예: 92=피흡수합병 984개사도 최신월까지 계속 데이터 존재) — 현재 데이터에는 월별 신규/폐업을 반영할 수 있는 필드 자체가 없음.

## 2. 조치

버그가 아니므로 데이터를 변경하지 않고, 오해를 줄이도록 라벨/설명만 보강:

- `frontend/src/pages/GlobalDashboard.tsx`, `mockup.html`: "전체 평가 기업 수" → **"관측 대상 전체 기업 수"**로 라벨 변경, 카드 하단에 "전체 관측기간(2021.01~2026.06) 내내 데이터가 있는 고정 패널 — 기준월을 바꿔도 동일" 설명 문구 추가.

## 3. 검증

`npx tsc --noEmit` 통과, Playwright로 실제 화면·mockup.html 카드 문구 반영 확인, 콘솔 에러 0건.
