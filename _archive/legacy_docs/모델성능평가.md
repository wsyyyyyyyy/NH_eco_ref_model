# 📊 기업 부도 예측(ECO Ref) 모델 성능 평가 보고서

이 문서는 LightGBM 기반의 조기경보시스템(EWS) 모델에 대한 최종 성능 평가 지표 및 비즈니스 임팩트를 요약한 통합 보고서입니다.

## 1. 🎯 모델 종합 성능 (Base Metrics)
- **알고리즘**: LightGBM
- **타겟 (Target)**: 향후 12개월 내 부도 여부 (`IS_BUDO_12M`)
  - **왜 12개월인가? (Data-Driven Decision)**: 모델링 전 EDA(탐색적 데이터 분석) 단계에서 부도 기업들의 '기준 시점 대비 부도 발생까지의 소요 기간(Time-to-Default)' 분포를 심층 분석했습니다. 그 결과, 위험 징후 발현 후 12개월 시점이 부도 예측의 통계적 변곡점이자 현업의 여신 회수 및 채권 보전이 가능한 최적의 골든타임으로 확인되어 최종 타겟을 `IS_BUDO_12M`으로 과학적으로 설정했습니다.
- **타겟 차주 (Target Audience: 중소기업 집중)**: 기업규모코드(`BZSCAL_C`) = 4.0 인 특정 기업군 제한
  - **왜 중소기업(4.0)만 타겟팅 했는가?**: 원천 데이터 병합 후 EDA 결과, 중소기업을 제외한 타 규모 기업군(대기업, 중견기업 등)은 부도 건수가 0~182건에 불과해 머신러닝 학습 모수가 극히 부족했습니다. 노이즈를 방지하고 부도의 91% 이상이 발생하는 핵심 집단에 정확도를 100% 집중하기 위해 타겟을 제한했습니다.
  
  | 기업규모 (BZSCAL_C) | 총 관측치 수 | 실제 부도 건수 | 비고 |
  | :--- | :--- | :--- | :--- |
  | **4.0 (중소기업)** | **1,775,314** | **2,586** | **🌟 최종 타겟** |
  | 5.0 | 171,378 | 182 | 부도수 부족 |
  | 2.0 (중견기업 등) | 55,080 | 6 | 부도 극소수 |
  | 8.0 | 43,362 | 66 | 표본 부족 |
  | 기타 (0.0, 1.0 등) | 28,284 | 0 | 부도 0건 |
- **데이터 분리 (Out-of-Time CV)**:
  - Train Set: 2023년 12월 이전 시계열 데이터
  - Valid Set: 2024년 1월 이후 미래 패널 데이터 (Out-of-Sample)
- **최종 ROC-AUC Score**: **`0.9011`** (우수한 리스크 판별력 입증)

## 2. 🔍 SHAP 기반 변수 중요도 (Feature Importance)
모델의 해석 가능성(Interpretability)을 확보하기 위해 SHAP Value 상위 50대 변수를 추출하였습니다.

![SHAP Top 50 Feature Importance](images/shap_summary_top50.png)

- **주요 발견점**: 재무 지표(자본총계, 차입금 의존도 등)와 거시 지표(환율 변동성), 비재무 지표(업력 등)가 종합적으로 부도 예측에 기여함을 시각적으로 확인했습니다. 
- 특히, 신용평가 점수(KIS SCORE)가 누락된 경우를 `-1`로 전처리한 것이, 모델 내에서 "점수 없는 영세 기업"이라는 강한 부도 시그널로 정확히 학습되어 상위권 변수로 작용했습니다.

## 3. 📉 다중공선성(VIF) 다이어트 및 경량화 성능 (Lean Model)
시스템의 안정적인 운영과 데이터 수집/유지보수 효율을 극대화하기 위해 VIF < 10 기준으로 모델의 변수를 압축했습니다.
- **변수 다이어트 결과**: 초기 `230`개 피처 ➡️ 핵심 `80`개 피처 (약 65% 경량화)
- **페널티 비용 검증**: 부도 탐지율(Recall)을 82.6%로 고정하고 비교 시, 변수를 150개 덜어낸 Lean 모델의 추가 오경보 발생은 전체 89만 건(Valid) 중 불과 **3,216건(0.36%)**에 그쳤습니다.
- **결론**: 예측력을 99% 이상 보존하면서 API 응답 속도 및 파이프라인 복잡도를 혁신적으로 절감했습니다.

## 4. ⚖️ 실무 비용 기반 최적 임계값 도출 (Cost & Threshold Optimization)
"부도 미탐 비용(False Negative)이 정상 기업 오탐 비용(False Positive)보다 압도적으로 높다"는 현업의 강력한 피드백을 수리적으로 모델에 반영했습니다.

![Threshold Optimization](images/threshold_optimization.png)

- **민감도 시뮬레이션**: 미탐 비용이 오탐 대비 10배, 20배, 50배 클 때의 최적 임계값 변동을 시뮬레이션.
- **최적 Threshold 구간**: `0.27 ~ 0.38` 구간이 부도 방어율과 현업 심사역의 업무 피로도 간의 최적 밸런스로 도출되었습니다. 
- 이 분석 결과는, 통계적으로 Recall(재현율)에 2배 가중치를 두어 계산한 수학적 **F2-Score의 최고점(`0.3797`)**과 완벽히 일치하여 강건성을 증명했습니다.

## 5. 📈 실전 Z-Score 5등급 변환 (Out-of-Sample Validation)
현업 심사역이 즉각적으로 직관적 이해가 가능하도록, 모델의 복잡한 Log-odds 출력값을 Z-Score 기준의 1~5등급(G1~G5) 체계로 정규화했습니다.

![Z-Score Correlation](images/corr_grade_pd.png)

- 미래 기간인 Valid Set (89만 건)을 대상으로 적용한 결과, **G1(안전)부터 G5(초고위험)로 갈수록 실제 부도율이 단 한 번의 역전 현상 없이 완벽하게 단조 증가(Monotonic Increase)**함을 확인했습니다.
- 특히 **G5 (초고위험)** 집단으로 분류된 약 17,453건의 예측 평가는, 이들의 실제 부도율이 무려 **29.58%**에 달해 모델의 강력한 스코어링 능력을 입증했습니다.

## 6. ⏱️ 핵심 가치: 기존 내부 모형 대비 '조기경보' 효과 (Early Warning Lead Time)
기존 은행 내부 조기경보모형이 **"안전(A등급)"**으로 오판하고 있던 거대한 집단 속에서, 본 AI 모델이 G5(시한폭탄)로 핀셋 적발해 낸 실제 부도 기업(175개 고유 차주)들의 **과거 등급 변경 궤적(Trajectory)**을 심층 추적했습니다.

1. **완전한 사각지대 해소 (63.4%, 111개 기업)**: 
   - 이 기업들은 **부도가 터지는 그 순간까지도 은행 내부 모형에서 끝내 'A등급'을 유지**했습니다. 
   - 즉, 기존 모형의 완전한 사각지대이며, AI 모델이 없었다면 은행은 부도 직전까지도 이들의 위험을 단 1%도 인지하지 못했을 것입니다.
2. **압도적인 조기 탐지 속도 (36.6%, 64개 기업)**: 
   - 내부 모형이 위험을 늦게나마 감지하여 부도 전 B등급으로 하향 조정한 기업들입니다. 
   - 그러나 이 경우에도 본 **AI 모델(G5 판별)이 기존 모형(B등급 강등)보다 평균 6.8개월이나 먼저 초고위험 상태임을 경고**한 것으로 나타났습니다.

> **💡 최종 비즈니스 결론**
> 본 모델은 단순한 정확도(AUC)의 수치적 향상을 뛰어넘습니다. 여신 심사 및 사후 관리(모니터링) 프로세스에 도입 시, **기존 인프라의 거대한 사각지대(63%)를 색출**해 냄과 동시에, 은행이 여신 한도 축소 및 채권 보전 등의 선제적 리스크 관리에 돌입할 수 있는 **약 반년(6.8개월)의 골든타임**을 안정적으로 제공하는 완벽한 실무형 조기경보시스템(EWS)입니다.
