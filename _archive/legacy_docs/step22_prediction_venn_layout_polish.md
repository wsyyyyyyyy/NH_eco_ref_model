# [Step 22] 예측 성공/실패 벤다이어그램 레이아웃 개선

> **작성일**: 2026-07-03
> **기준**: Step 21에서 추가한 벤다이어그램의 배치/가독성 문제 수정

---

## 1. 문제

- 벤다이어그램 카드가 페이지 전체 폭을 혼자 차지해 우측에 빈 공간이 많았음 — 원인은 새로 추가한 두 섹션(벤다이어그램, 등급분포 차트)을 감싼 컨테이너가, 이미 PD-LAG·업종별 매트릭스 전용으로 닫혀버린 기존 `grid-2` 밖에 위치했기 때문(같은 그리드가 아니라 각각 독립된 행으로 렌더링됨).
- 벤다이어그램 내부 라벨("ERM만 포착", "둘 다 포착")이 원 도형 안에 겹쳐서 표시되어 가독성이 떨어짐.

## 2. 조치

- `GlobalDashboard.tsx`: 벤다이어그램 카드와 등급분포 바 차트를 새로운 `grid-2` 컨테이너로 묶어 한 행에 나란히 배치.
- 벤다이어그램 라벨을 원 안쪽 텍스트 방식에서 `VennBadge` 컴포넌트(영역 내부의 점 → 리더라인 → 색상 강조 뱃지)로 교체. ERM만/둘 다/내부만 세 영역 모두 원 밖으로 라벨을 빼고, 각 영역 색상에 맞춘 테두리+배경으로 시각적 구분을 강화.
- "둘 다 놓침" 캡션을 별도 범례 점과 함께 하단에 두 줄로 분리해 다른 뱃지와의 겹침 제거.
- 리드타임 통계 영역("전체 포착률", "ERM 단독 사각지대") 텍스트 줄바꿈 깨짐 수정 (`whiteSpace: nowrap`).

## 3. 검증

- `npx tsc --noEmit` 통과.
- Playwright로 `/global` 실 렌더링 재확인, 라벨 겹침 없이 정상 표시, 콘솔 에러 0건.
