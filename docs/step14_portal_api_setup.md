# Step 14. 가상 지점 포털 백엔드 API (FastAPI) 구축

본 문서는 조기경보 가상 지점 포털(Virtual Branch Portal)의 원활한 데이터 통신을 위해 구축된 백엔드 API 서버의 구조와 기능을 설명합니다. 해당 서버는 프론트엔드(React)가 194만 건의 데이터를 즉시 조회하고, AI(Gemini)와 실시간 인퍼런스(LightGBM)를 수행할 수 있도록 돕는 미들웨어 역할을 수행합니다.

## 1. 아키텍처 및 기술 스택
- **프레임워크:** FastAPI (비동기 처리 지원 및 Swagger 문서 자동 생성)
- **데이터 엑세스:** DuckDB (초고속 인메모리/파일 기반 분석 DB 연동)
- **AI 연동:** Google Generative AI (Gemini 2.5 Flash API 연동)

## 2. 모듈별 라우팅(Routers) 상세 설명

### 1) `dashboard.py` (대시보드 글로벌 뷰)
- **엔드포인트:** `/api/dashboard/summary`
- **역할:** 설정된 기준 일자(`base_ym`)에 맞춰 은행 전체의 관리/주의/우량 기업 통계와, 5대 가상 지점(VB001~VB005)별 고위험(G4, G5) 차주 분포 등을 집계하여 반환합니다.

### 2) `borrowers.py` (차주 리스트 및 상세 정보)
- **엔드포인트:** 
  - `/api/borrowers` (특정 지점의 고위험 차주 리스트 Pagination 지원)
  - `/api/borrowers/{bzno}` (특정 차주의 세부 재무/비재무 데이터 반환)
- **역할:** 프론트엔드 화면에서 무한 스크롤 및 차주 명세서 클릭 시 데이터를 즉각적으로 Fetch 해오는 핵심 조회 쿼리입니다.

### 3) `ai.py` (Gemini 기반 관리 팁)
- **엔드포인트:** `/api/ai/tips`
- **역할:** 특정 차주의 상세 데이터를 프롬프트로 가공하여 로컬 환경(`.env`)에 저장된 Gemini API로 전송합니다. 이후 지점장(심사역)이 참고할 수 있는 "맞춤형 차주 관리 팁 3가지"를 실시간 생성하여 반환합니다.

### 4) `simulation.py` (거시경제 시뮬레이터)
- **엔드포인트:** `/api/simulation/`
- **역할:** 화면의 슬라이더(금리, 환율, 소비자물가지수 등) 값이 변동될 때마다 호출되며, 1차적으로 구축된 LightGBM 모델을 실시간 통과시켜 부도 위험이 급등/급락하는 산업군을 재평가해주는 킬러 서비스 라우터입니다.

---

```bash
python -m uvicorn backend.main:app --reload
```
