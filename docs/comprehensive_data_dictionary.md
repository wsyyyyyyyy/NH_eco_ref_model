## 1. 원본 데이터 (Raw Data - 은행 내/외부 11대 원장)

`input/` 디렉토리에 적재되는 11개의 파이프(`|`) 구분 텍스트 파일 및 엑셀 메타데이터 원장입니다. DuckDB 데이터웨어하우스(`raw_*` 테이블)에 1:1로 매핑되며, 원장 성격에 따라 **단건 마스터, 연도별, 분기별, 월별, 이벤트 시점** 등 입도가 다릅니다.

* **테이블 수집 주기 및 입도**: **단건 마스터 (Single Snapshot / Static Master)** - 기업별 고유 기본 식별 정보 (변동 시 업데이트)

| :--- | :--- | :--- | :--- | :--- | :--- |
| `V_BZNO` | 가상 사업자등록번호 (차주 식별자) | `VARCHAR(10)` | **단건 (Master)** | `1000001234` | PK, 마스킹 처리 |
| `CONM` | 기업명 (상호) | `VARCHAR(100)` | **단건 (Master)** | `(주)에코첨단소재` | 가상 기업명 |
| `STD_INDS_CFC` | 한국표준산업분류 코드 (KSIC 10차) | `VARCHAR(5)` | **단건 (Master)** | `C29111` | C(제조업), G(도소매) 등 |
| `ESTB_DT` | 기업 설립일자 (YYYYMMDD) | `VARCHAR(8)` | **단건 (Master)** | `20120514` | 업력(Business Age) 계산용 |
| `ENTP_SCL_CFC` | 기업 규모 구분 코드 | `VARCHAR(2)` | **단건 (Master)** | `02` | 01: 대기업, 02: 중소기업 |
| `MAIN_PROD_NM` | 주력 생산 제품 및 서비스명 | `VARCHAR(200)` | **단건 (Master)** | `2차전지 양극재, 배터리 케이스` | 텍스트 분석용 |

## 2. 통합 데이터 및 파생변수 (Integrated Panel & Derived Features)

원본 데이터들을 `BAS_YM`(기준년월) 기준으로 병합하고, 금융 공학 도메인 지식을 결합하여 새롭게 생성한 **12개월 Forward-Looking 부도 예측용 최종 통합 패널(`nh_panel_macro_12m.csv`)** 명세입니다.  
* **통합 패널 테이블 기본 입도**: **월별 시계열 패널 (Monthly Panel / 매월 말 기준 194만 건)**

### 2.1 종속변수 (Target Variables)
머신러닝 모형이 예측하고자 하는 부도 정의 및 잔여 기간 변수입니다.

| 컬럼 영문명 | 컬럼 한글명 / 데이터 구성 | 데이터 형태 | 수집 주기 / 입도 | 데이터 예시 | 비고 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `TARGET_12M` | **12개월 내 부도 발생 여부 (Target)** | `INTEGER` | **월별 (Monthly Panel)** | `1` (부도) / `0` (정상) | 매월 말 기준 향후 12M 관찰 |
| `TTD` | 부도까지 잔여 관찰 월수 (Time-to-Default) | `INTEGER` | **월별 (Monthly Panel)** | `6.8` (6.8개월 후 부도) | 12개월 관찰 윈도우 기반 |
| `IS_DEFAULT_HIST` | 과거 부도 이력 보유 여부 | `INTEGER` | **월별 (Monthly Panel)** | `0` (없음) / `1` (보유) | 과거 누적 이력 플래그 |

### 2.2 재무 건전성 및 수익성 파생변수 (Financial Ratios)
원장 재무 항목(`JEMU`)을 사칙연산하여 산출한 핵심 파생변수입니다.  
* **입도 특성**: 재무제표의 원본 생성 주기는 **연도별(Annual)**이지만, 통합 패널에서는 매월 최신 공시 재무값을 매핑하는 **월별(Monthly - Forward Filling)** 방식으로 관리됩니다.

| 컬럼 영문명 | 컬럼 한글명 / 데이터 구성 | 데이터 형태 | 수집 주기 / 입도 | 데이터 예시 | 산출 공식 및 의미 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `DEBT_RATIO` | 부채비율 (%) | `DOUBLE` | **연결산 → 월별 매핑** | `176.84` | `(TOT_DEBT / TOT_EQUITY) * 100` (재무 안전성) |
| `CURRENT_RATIO` | 유동비율 (%) | `DOUBLE` | **연결산 → 월별 매핑** | `142.50` | `(유동자산 / 유동부채) * 100` (단기 상환 능력) |
| `INTEREST_COVERAGE`| 이자보상배율 (배) | `DOUBLE` | **연결산 → 월별 매핑** | `4.40` | `OP_PROFIT / INT_EXPENSE` (<1.0이면 한계기업) |
| `ROE` | 자기자본이익률 (%) | `DOUBLE` | **연결산 → 월별 매핑** | `21.72` | `(NET_INCOME / TOT_EQUITY) * 100` (자본 수익성) |
| `ROA` | 총자산이익률 (%) | `DOUBLE` | **연결산 → 월별 매핑** | `7.85` | `(NET_INCOME / TOT_ASSET) * 100` (자산 운영 효율) |
| `OP_MARGIN` | 영업이익률 (%) | `DOUBLE` | **연결산 → 월별 매핑** | `7.68` | `(OP_PROFIT / SALES) * 100` (본업 수익성) |
| `SALES_GROWTH` | 전년 대비 매출액 증가율 (%) | `DOUBLE` | **연결산 → 월별 매핑** | `12.40` | `(SALES_t - SALES_{t-1}) / SALES_{t-1} * 100` |
| `ASSET_TURNOVER` | 총자산회전율 (회) | `DOUBLE` | **연결산 → 월별 매핑** | `1.56` | `SALES / TOT_ASSET` |

| `BUSINESS_AGE` | 기업 업력 (월 단위) | `INTEGER` | **월별 (Monthly)** | `142` (11년 10개월) | `BAS_YM` - `ESTB_DT` (신생 기업 리스크 가중) |

### 2.4 ERM AI 모형 최종 산출 변수 (AI Model Outputs)

| 컬럼 영문명 | 컬럼 한글명 / 데이터 구성 | 데이터 형태 | 수집 주기 / 입도 | 데이터 예시 | 비고 |

## 3. 외부 API 및 수집 데이터 (External API, Macro & News Overlay)

기업 내부 재무제표의 한계(후행성)를 극복하기 위해 외부 한국은행(ECOS), CB사, 그리고 뉴스 공시 API를 연계하여 수집한 동적 데이터입니다.

### 3.1 거시경제 시계열 지표 (Macroeconomic Indicators - `step4_macro.py`)
한국은행 Open API 및 경제통계시스템에서 수집하여 월별(`BAS_YM`)로 매핑한 거시 변수입니다.

| 컬럼 영문명 | 컬럼 한글명 / 데이터 구성 | 데이터 형태 | 수집 주기 / 입도 | 데이터 예시 | 경제적 영향도 및 모델 활용 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `BASE_RATE` | 한국은행 기준금리 (%) | `DOUBLE` | **일별 수집 → 월별 매핑** | `3.50` | 변동금리 대출 이자 부담 급증 (이자보상배율 악화) |
| `EXCHANGE_RATE_USD`| 원/달러 환율 (원) | `DOUBLE` | **일별 수집 → 월말/평균 매핑** | `1,345.50` | 수입 원자재가 상승 및 외화부채(`AC12`) 상환 부담 |
| `CPI_INFLATION` | 소비자물가상승률 (전년동월대비 %) | `DOUBLE` | **월별 공시 (Monthly)** | `3.10` | 원가 상승 및 내수 소비 위축 효과 |
| `OIL_PRICE_WTI` | WTI 국제 원유 가격 (달러/배럴) | `DOUBLE` | **일별 수집 → 월말/평균 매핑** | `82.40` | 제조업, 물류운수업 에너지 원가 충격 |
| `GDP_GROWTH` | 국내총생산 실질 성장률 (%) | `DOUBLE` | **분기별 공시 → 월별 매핑** | `1.40` | 국가 전반의 경기 동향 및 매출 성장률 커플링 |

### 3.2 실시간 뉴스 감성 및 공시 오버레이 (News & Disclosure Overlay - `step5_news_overlay`)
기업별 뉴스 보도, 법정 관리, 소송, 횡령 등 외부 비정형 데이터를 API로 실시간 수집·지수화한 동적 대체 지표입니다.

| 컬럼 영문명 | 컬럼 한글명 / 데이터 구성 | 데이터 형태 | 수집 주기 / 입도 | 데이터 예시 | 데이터 소스 및 의미 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `NEWS_SENTIMENT_SCORE`| 뉴스 자연어 감성 지수 (-1.0 ~ +1.0) | `DOUBLE` | **일별 수집 → 월별 롤링** | `-0.82` (매우 부정적) | 뉴스 헤드라인 NLP 텍스트 마이닝 감성 분석 |
| `NEWS_RISK_COUNT`| 최근 30일 내 부정 리스크 보도 건수 | `INTEGER` | **일별 수집 → 30일 롤링** | `5` (5건 보도) | '연체', '소송', '가압류', '파업' 키워드 필터 |
| `DISCLOSURE_RISK_YN`| 주요 공시 의무 위반 / 불성실 공시 여부 | `INTEGER` | **실시간/이벤트 → 월별 매핑** | `0` (정상) / `1` (위반) | 금융감독원 DART API 실시간 연계 |
| `NEWS_OVERLAY_INDEX`| **종합 뉴스/공시 리스크 오버레이 지수** | `DOUBLE` | **월별 산출 (Monthly)** | `85.4` (위험 경보) | 감성지수 + 보도건수를 결합한 0~100점 스트레스 인덱스 |

### 3.3 외부 CB사 신용평가 API 연계 데이터 (External Credit Bureau Data)
NICE평가정보 및 한국기업평가(KIS)에서 수집하는 외부 공인 신용평가 원장입니다.

| 컬럼 영문명 | 컬럼 한글명 / 데이터 구성 | 데이터 형태 | 수집 주기 / 입도 | 데이터 예시 | 비고 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `NICE_CREDIT_SCORE` | NICE 종합 신용평점 (300~1000점) | `INTEGER` | **연도별 / 정기 평가** | `745` | `CG01` 원장 매핑 (상호대조 검증용) |
| `KIS_CRI_GRADE` | 한국기업평가 CRI 신용등급 (AAA~D) | `VARCHAR(5)` | **연도별 / 유효기간 기준** | `BBB0` | `C302` 원장 매핑 (기업 신용 서열) |
| `CB_DELINQUENCY_AMT`| CB사 공유 금융기관 총 연체 잔액 (천원) | `BIGINT` | **이벤트 발생 / 월별 매핑** | `0` (연체 없음) | `VH_CRIF` 연체 총액 |
