# NH ECO Ref Model — 발표 대본 (마스터 드래프트)

> **이 드래프트는 무엇인가**
>
> 기업 부도 조기경보 모델 프로젝트의 발표용 슬라이드 기획안 + 발표 대본이다.
> **모든 수치는 `docs/01~07` 및 `eda_pipeline/output/validation/` 산출물과 일치한다.**
> 이전 판(투트랙·VIF Diet·+12.9개월·AUROC 0.65→0.90+·194만 건 등)은 **현행과 다른
> 모형 서술**이라 전면 폐기하고 다시 썼다. 구세대 수치는 07 문서 §0 의 인용 금지
> 목록을 따른다.
>
> 발표의 축은 하나다 — **"성능이 아니라 방법"**. 높은 초기 성능이 시점 누수였음을
> 측정으로 증명하고, 누수를 제거하고 다시 만들었다는 이야기다.

## [Part 1. 배경]

### Slide 01. 표지

- **제목**: 기업 부도 조기경보 모델 — 성능의 상당 부분이 시점 누수였음을 측정으로
  증명하고, 제거한 뒤 다시 만든 기록
- **부제**: 향후 12개월 내 부도 예측 · LightGBM · 27,147사 / 948,214행 (2021-01~2025-05)
- **한 줄**: "AUC 0.85 를 자랑하는 발표가 아니라, 0.94 가 왜 가짜였는지 밝히는 발표입니다."

### Slide 02. 왜 조기경보인가

- **대본**: 신용위험 관리의 무게중심을 '사후 평가'에서 '사전 감지'로 옮기는 것이
  목표입니다. 부도가 난 뒤 등급을 내리는 것은 행정 절차이지 경보가 아닙니다.
  여신을 회수하거나 담보를 보강할 시간을 벌려면, 재무제표가 나빠지기 전에 신호를
  잡아야 합니다.
- **시각화**: 부도 전 12개월 타임라인 — 관측시점 t 에서 t+1~t+12 구간의 부도를 예측.

### Slide 03. 무엇을 예측하는가 (타겟 정의)

- **타겟**: `IS_BUDO_12M` — 관측시점 t 기준 `t < 부도월 ≤ t+12` 이면 1.
- **부도 이벤트**: 1,286건 / 1,192사 (원천 BUDO 집계).
- **★ 반드시 짚을 점**: 부도사유의 **88.9%(1,143건)가 "타행불량"** 이다. 즉 이
  모델이 예측하는 것은 "당행 차주가 **어딘가에서** 부실화되는 사건" 이고, 당행 자체
  대손과는 다르다. 경보 = 당행 손실 예측이 아니다.
- **정합성 처리**: 부도월 자체 제외, 부도~정상화 구간만 제외 후 정상 관측 복귀,
  재부도는 새 이벤트. 다중부도 기업의 전 구간 복제(행 중복)를 `merge_asof` 로 제거.

### Slide 05. 전처리 — 시점 정합성이 전부다

- **재무 as-of**: 12월 결산이 98.37%. 12월 재무제표는 이듬해 4월에 조회 가능하므로
  `AVAIL_YM = 결산월 + 4개월` 로 두고 `merge_asof`. 검증은 "값이 바뀌는 달의 분포" —
  `JEMU_115000` 변경의 97.41%가 4월이면 as-of 가 작동한 것.
- **Sentinel 디코딩**: 재무 계정의 특수값(10001 흑자→적자 등)을 원계정 재계산으로
  대조 해독(부호 일치 97~100%). `10000`(이자비용 0 = 무차입 등)은 결측이 아니라 실체.
- **결측 3분류**: 구조적 부재(0 + 플래그) / 미해당(별도 범주) / 진짜 결측(NaN 유지).
- **거시 공표 시차 그룹 A(+0)~D(+3)**: ECOS 실데이터 최종 수록월을 직접 관측해 배정
  (측정일 2026-09-01 의존 — 월초 관측이라 직전월 공표를 못 볼 수 있음, 재검증 대기).

## [Part 3. 누수 — 이 발표의 핵심]

### Slide 06. 처음 성능이 왜 의심스러웠나

- 초기 모델의 gain 상위는 재무가 아니라 **CB 신용불량 사유(36.34%) · 외부 신용평점
  (14.51%) · 기업 개폐업 코드** 였다. 세 변수가 gain 의 3분의 2.
- 세 변수 모두 "부도의 원인" 이 아니라 **"부도의 결과이거나 부도 이후 확정되는 값"**.
  - 신용불량: 발생과 부도의 gap 중앙값 −2개월, 75.9%가 부도가 먼저.
  - 신용평점: 원천이 연도별 wide 포맷, 날짜 컬럼 없음.
  - 개폐업 코드: 2026년 추출 시점 스냅샷. 폐업 기업 부도율 34.8% vs 전체 3.7%.
- **신호 셋**: 단일 변수 집중도 / Train−Valid 격차가 거꾸로 좁아짐 / gain 순위와 실제
  기여의 불일치.
- <sub>출처: `docs/04` §1</sub>

### Slide 07. 진단 방법 — 조인 단위 감사

- **원리**: 어떤 컬럼이 한 기업의 같은 연도 12개 행에서 한 번도 안 변하면, 그것은
  월이 아니라 **연도를 키로 붙은 것**이다. 연 단위로 붙었다면 그해 후반 값이 그해
  1월 행에 들어간다 — 시점 누수.
- **판정식**: `GROUP BY V_BZNO, SUBSTR(BASE_YM,1,4) HAVING COUNT(DISTINCT 컬럼) > 1`
  이 0 이면 연 단위 조인.
- **★ 이름이 같은 두 플래그의 판정이 갈렸다**: `C302_MISSING_YN`(유효기간 as-of,
  월별 변동 21,040건 → **정합**) vs `CG01_MISSING_YN`(연 단위 merge, 변동 0 → **누수**).
  이름·정의·데이터 딕셔너리로는 구분 불가. **조인 로직만이 갈라낸다.**
- 같은 도구로 `AC12` 계열 11개의 동일 결함을 추가 발견 (수동 목록에 없던 것).
- <sub>출처: `docs/04` §2</sub>

### Slide 08. ★ 3층 성능 — 무엇이 성능을 만들었는가

| 층 | 구성 | Valid AUC | 의미 |
|---|---|---|---|
| **누수 포함 상한 (A7)** | 누수 변수를 전부 되넣음 | **0.9398** | 미래 정보를 쓰면 여기까지 나온다 (성능으로 인용 안 함) |
| **누수 제거 하단 (A0c)** | 시점 정합 피처만, C302 정합분도 제외 | **0.7826** | 가장 보수적인 기준선 |
| **최종 구성 (D8)** | C1 기반 + 거시 상호작용 14 + 단조 제약 | **0.8548** | 시점 정합성을 지킨 값 (시드 3회, σ 0.0015, 규제 R2, 169피처) |

- **같은 변수를 두 번 측정한다** — CRIF 를 연 단위 조인 상태로 재면 A0 대비 **+0.0379**,
  월 단위 as-of 로 재구성하면 **−0.0002**(노이즈). 바꾼 것은 조인 단위 하나. **그 차이가
  누수분이다.**
- 정확한 결론: **"초기 성능이 전부 누수였고 실제는 0.78" 이 아니다.** 0.94 와 0.78
  사이에서, 시점 정합성을 지키며 살릴 수 있는 정보(업종 대분류만 쓰기, C302 정합분)를
  제대로 살리면 **0.85 수준을 회복**한다.

## [Part 4. 모델]

### Slide 09. 학습 조건과 판정 규칙 (결과를 보기 전에 정한 것)

- **분할**: Train ~202309 / Dev 202310~202312 / Valid 202401~202505.
  early stopping 은 **Dev** 로 (Valid 를 보지 않는다).
- **규제 R0→R2**: Dev−Valid 격차 R0 0.2416 → R2 0.2142. R2 채택
  (`num_leaves=7, reg_alpha=5, reg_lambda=5`). 규제 후에도 Train AUC 0.998 인 것은
  양성 108배 가중 때문이며 파라미터로 막기 어렵다 — 의미 있는 지표는 Dev−Valid 격차.
- **시드 규칙**: 통합 σ ≈ 0.0014 → `|ΔAUC| < 0.003` 은 "차이 없음".
- **★ 교훈**: 시드 3회는 σ 를 **과소추정**한다. 한 구성의 안정성 이득을 3회에서
  "10배" 로 관찰했으나 10회에서 1.5~1.8배였다 (MAPE σ 는 3회 0.62 → 10회 3.20).
- <sub>출처: `docs/03` §1·§2 · `docs/07` §4-4</sub>

### Slide 10. 거시경제 결합 — 3층으로 읽어야 한다

- 거시 원본을 그대로 넣으면 같은 달 모든 기업이 같은 값 → **시점 더미로 퇴화**
  (초기 모델에서 거시 172개 중 85개가 한 번도 분기에 안 쓰임).
- 해법: **거시 충격 × 기업 노출도** 상호작용항.
- **3층**: 수집 **63개 원지표** → 4구간(Train 전반/후반/전체/Valid) 부호 검사 통과 →
  **상호작용항 14개**. (검사 대상 97 / 부호 일치 15 / 상관 임계까지 통과 10 + 완화
  편입 5 / 압축 후 14 — 상세는 `docs/05` §7)
- **★ "거시 14개가 고르게 작동한다" 가 아니다.** `ix_KORIBOR_spread_d12__liq` 한 항이
  거시 gain 0.93% 중 약 0.6%p 를 담당하고, 나머지 13개는 계열 다양성을 확보하지만
  기여는 미미하다.
- **원인 규명**: 관측 53개월에 금리 사이클이 한 번뿐이라, 금리·스프레드 계열의 부호가
  Train↔Valid 에서 뒤집힌다(`base_rate` Train +0.977 / Valid −0.918). 부도가 거시에
  **후행**하기 때문 — corr(부도율[t], base_rate[t−k]) 이 k=4개월에서 단봉(r=0.918).
- <sub>출처: `docs/05` §2·§5·§7·§8</sub>

### Slide 11. 등급 체계

- **5단계 리스크 등급 (G1~G5)** — 로그오즈를 표준화한 **Z-Score** 를 등폭 컷오프
  `[−1, 0, +1, +2]` 로 자른다 (μ=−4.1864, σ=2.8373, Valid 기준).
  확률을 직접 자르지 않는 이유: PD 가 0 근처에 몰려 있어 등분할이 하위 등급을 구분
  못 함.
- **16단계 표기 등급 (AAA~CCC)** — raw PD 분위. 기존 CB 등급과 눈높이 맞춤.
- **두 체계는 어긋나지 않는다** — 948,214행 전수에서 순위 역전 0건. 확률 보정
  (raw/platt) 을 바꿔도 등급은 불변(단조 변환).
- 등급별 부도율 (Valid): G1 0.06% → **G5 18.55% (Lift 15.12)**. 단조 확보.

## [Part 5. 비즈니스 임팩트]

### Slide 12. ★ 여신 상위 10% 만 집중 관리해도 부도 기업의 4분의 3을 잡는다

- **Valid 홀드아웃 (202401~202505, 312,334행 / 부도 기업 554사, out-of-sample)**:

  | 집중 관리 범위 | 부도 기업 포착 | Lift |
  |---|--:|--:|
  | 상위 10% | **75.3% (417/554)** | 5.64 |
  | 상위 20% | 89.2% (494/554) | 3.73 |
  | 상위 30% | 93.5% (518/554) | 2.77 |

- **대본**: AUC 0.8548 이라는 숫자보다 이 표가 실무에 가깝습니다. 심사역이 전체
  차주를 같은 강도로 볼 수는 없습니다. 예측 부도확률 상위 10% 만 집중 관리해도,
  학습에 쓰지 않은 구간에서 실제로 부도한 기업의 75.3% 를 미리 골라냅니다.
- **보조**: 긴축기(Train)에 상위 10% 경보가 났던 기업 3,238사 중 305사가 인하기
  (Valid)에 부도 — 경보군 부도율 9.42% vs 비경보 1.34% (Lift 7.02). 긴축 충격이
  시차를 두고 실현된다는 관측과 정합 (k=4 상관). *단, 인하기=Valid 구간이라 관측
  사실로만 인용.*
- <sub>출처: `C1_venn_results.md` §B·§C</sub>

### Slide 13. ★ 차별점 — 재무제표는 양호한데 부도한 기업

- **정의**: NICE CRI 등급 서열 상위 50%(양호)이면서 부도한 기업.
- **D8 상위 10% 포착**: 전 구간 **84.3% (97/115)** / Valid 단독 59.4% (38/64).
- **대본**: 내부 조기경보모형은 재무 지표를 중심으로 만들어집니다. 재무제표상
  양호한 기업은 그 구조상 잡기 어렵습니다. 본 모형은 이 그룹의 84.3% 를 상위 10%
  안에 포착했습니다.
- **★ 반드시 함께 말할 것**: 내부 모형과의 **직접 대조는 하지 못했습니다.** 내부
  모형 부도율 데이터가 11개월(전부 저금리기·전부 학습 구간)에만 있어 비교 조건이
  성립하지 않습니다. 따라서 이것은 **간접 증거**이며, "내부 모형이 몇 % 를 놓쳤다"
  같은 수치는 만들지 않았습니다.
- <sub>출처: `C1_venn_results.md` §D · `docs/06` §2 · `docs/07` §4-12</sub>

### Slide 14. 거시 상호작용의 전달 구조 — 부호가 아니라 구조를 본다

- 포털의 거시 시뮬레이터는 구 모델 기준이라 D8 과 피처 교집합 0. **독립 스크립트**
  (`step44_macro_stress_d8.py`)로 D8 상호작용항을 직접 재계산했다.
- **보여주는 것은 두 가지뿐**:
  1. **노출도 상호작용이 기계적으로 작동한다** — 거시 충격이 기업별 노출도에 따라
     다르게 전달된다.
  2. **반응 크기가 레버리지에 비례한다** — 차입금의존도 상위 25% 의 변화폭이 전체보다
     크다.
- **부호는 해석하지 않는다** — 신용스프레드 채널은 4구간 부호 검사 탈락으로 D8 에서
  제외(효과 0). KORIBOR 스프레드는 부호가 이론과 반대(단일 사이클 표본 한계, `docs/05`
  §5). **스트레스 시나리오 수치로 쓸 수 없다.**
- 부호가 방어 가능한 예: **수출물량 −10%p → 포트폴리오 PD +0.021%p, 고레버리지
  +0.030%p** (단조 제약 −1 항). 방향은 맞으나 폭은 작다.

## [부록] 예상 질의응답

### Q1. "AUC 0.85 면 기존 모형보다 나은 겁니까?"

기존 내부 모형과의 직접 비교는 하지 못했습니다. 내부 모형 부도율 데이터가 11개월
(전부 저금리기·전부 학습 구간)에만 존재해 비교 조건이 성립하지 않습니다. 그래서 이
발표는 "내부 모형 대비 몇 %p" 를 주장하지 않습니다. 대신 검증 가능한 것을 말합니다 —
학습에 쓰지 않은 구간에서, 예측 상위 10% 만 관리해도 부도 기업의 75.3% 를 잡습니다.

### Q2. "그럼 처음 나온 AUC 0.94 는 뭐였습니까?"

시점 누수입니다. 연 단위로 조인된 신용불량·신용평점 변수가 관측시점 이후의 정보를
끌어오고 있었습니다. 같은 변수를 조인 방식만 월 단위 as-of 로 바꿔 다시 재면 기여가
+0.038 에서 노이즈 수준으로 사라집니다. 0.9398 은 "시점 정합성을 지키지 않으면 이런
값이 나온다" 는 상한으로만 인용합니다.

### Q3. "거시경제 변수를 63개나 수집했는데 gain 기여가 1% 도 안 됩니까?"

그렇습니다. 숨기지 않습니다. 원인은 관측 기간에 금리 인상→인하 사이클이 한 번뿐이라,
금리·스프레드 계열의 부호가 학습 구간과 검증 구간에서 뒤집힌다는 것입니다. 97개 변환
변수를 4구간 부호 검사에 넣어 10개만 통과했습니다. 거시가 실제로 기여하는 채널은
사실상 금리 스프레드 하나입니다.

### Q4. "거시 시뮬레이터에서 금리를 올렸는데 부도확률이 내려갑니다."

같은 이유입니다 — 단일 금리 사이클 표본의 부호 반전. 그래서 그 결과를 스트레스
시나리오 수치로 제시하지 않습니다. 시뮬레이터가 보여주는 것은 방향이 아니라 전달
구조입니다 — 거시 충격이 기업별 노출도에 따라 다르게 전달되고, 차입이 많은 기업이
더 크게 반응한다는 것.

### Q5. "포털에서 거시 시뮬레이션이 최종 모델로 동작합니까?"

아닙니다. 포털은 아직 구 모델을 로드하고, 최종 모델(D8)과 피처 교집합이 0 입니다.
발표의 거시 스트레스 수치는 포털이 아니라 독립 스크립트로 산출한 것이고, D8 포털
연동은 향후 과제로 명시했습니다.
