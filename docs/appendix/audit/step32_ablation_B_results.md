# STAGE 6 Ablation — B축 (패널 변종)

실행일: 2026-08-30 · 규제 **R2** · 재현: `python -m eda_pipeline.step32_panel_variants --variant B1 --train`
원자료: `stage6_ablation/ablation_B_results.json`

**판정 규칙 (A축과 동일)**: 시드 σ ≈ 0.0014~0.0025.
**|ΔAUC| < 0.003 은 "차이 없음"으로 기술한다.** ΔAUC 가 0.01 미만이면 시드 3회로 판정한다.

## 1. B1 — 행 중복 미제거

### ★ 지시서의 "양성 9,985 → 63,531 (4.9배)" 가 재현되지 않는다

`generate_12m_target` 을 구 `merge(on='V_BZNO')` 로 되돌린 결과:

```
행수  951,908 → 954,923   (+3,015, +0.32%)
양성  9,814  → 10,251     (+437,  +4.5%)
기여기업 988사 → 988사    (변화 없음)
```

**행 중복의 효과는 미미하다.** 원인은 명확하다 —
`budo_events.csv` 는 1,281건 / 1,192사인데 **다중부도 기업이 80사뿐**이다.
`merge(on='V_BZNO')` 의 복제량은 다중부도 기업 수에 비례하므로 거의 늘지 않는다.

### 63,531 의 출처 추적

| 조합 | 행수 | 양성 |
|---|---:|---:|
| 현행 (obv 스파인 + `merge_asof` + budo_events) | 948,214 | 9,814 |
| **B1** (obv 스파인 + 구 merge + budo_events) | 954,923 | **10,251** |
| legacy 패널 + 구 merge + `IS_BUDO_YN` 원천 | 2,177,585 | **22,906** |
| 지시서 인용값 | ? | **63,531** |

**이 체크아웃의 어떤 조합으로도 63,531 이 재현되지 않는다.**
`nh_panel_full.csv`(legacy)는 2,171,130행 / 66개월(202101~202606)로 현행 패널
(948,214행 / 53개월)의 2.3배이며, 구 방식 타겟을 그대로 재현해도 22,906 이다.

63,531 은 절단(censoring) 보정 이전, 또는 '부도 진행 중 구간 제외' 이전 상태에서
나온 값으로 보인다. 그 파이프라인 상태가 이 체크아웃에 없다.

→ **"행 중복 제거로 양성이 63,531 → 9,985 로 줄었다"는 귀속은 근거가 확인되지
않는다.** 실제 행 중복 단독 효과는 **+437 양성 (+4.5%)** 이다.
STAGE 7 보고서에서 4.9배 수치를 인용하지 말 것.

### 교란 통제 — 피처 20개 차이

B1 패널에는 A0 피처 152개 중 **20개가 없다.** `exp_fx` / `exp_fx_dbt` /
`exp_rate` / `exp_liq` / `exp_inv` / `is_manufacturing` 등 노출도 계열은
`step6` 산출물인데 B1 은 `step5` 까지만 돌렸기 때문이다.

그대로 비교하면 **타겟 생성 방식과 피처 20개 차이가 섞인다.** 따라서 A0 를
같은 132 피처로 제한한 대조군(`A0c132`)을 시드 3회로 돌렸다.

| 구성 | 피처 | 시드 42 | 7 | 2024 | 평균 | σ |
|---|---:|---:|---:|---:|---:|---:|
| A0 (전체) | 152 | 0.8434 | 0.8435 | 0.8442 | 0.8437 | 0.0004 |
| **A0c132 (대조군)** | 132 | 0.8514 | 0.8525 | 0.8552 | **0.8530** | 0.0019 |
| **B1 (구 타겟)** | 132 | 0.8476 | 0.8527 | 0.8515 | **0.8506** | 0.0027 |

### ★ 판정 — 차이 없음. 그리고 시드 규칙이 판정을 뒤집은 사례

**B1 − A0c132 = −0.0024 = 0.9σ → 판정 불가. 행 중복은 성능에 영향이 없다.**

단일 시드(42)만 보면 B1 0.8476 vs 대조군 0.8514 로 **−0.0054** 였고, 이것만으로는
"행 중복이 성능을 떨어뜨린다"고 결론 내릴 뻔했다. 시드 3회 평균은 **−0.0024** 로
노이즈 구간이다. B1 자체의 시드 표준편차가 0.0027 로, 단일 시드 차이 −0.0054 의
절반이 시드 변동이었다.

**|ΔAUC| < 0.01 이면 시드 3회로 판정한다는 규칙이 실제로 결론을 바꿨다.**
이 사례를 STAGE 7 방법론 섹션에 넣는다.

### 종합

행 중복 미제거의 실제 효과:
- 양성 **+437 (+4.5%)**, 행수 +3,015 (+0.32%), 기여기업 변화 없음
- Valid AUC **차이 없음** (−0.0024, 0.9σ)

즉 이 패널에서 행 중복은 **양성 수를 소폭 부풀리지만 모델 성능에는 영향이 없다.**
"4.9배 부풀림" 도, "제거로 성능이 개선됐다" 도 이 데이터로는 뒷받침되지 않는다.

## 1b. ★ 라벨이 바뀐 변종은 AUC 를 직접 비교할 수 없다

B1b 를 돌리고 나서야 드러난 제약이다.

| 패널 | 전체 양성 | Valid 양성 |
|---|---:|---:|
| 현행 A0 | 9,814 | 3,832 |
| B1 (구 merge) | 10,078 | 3,878 (+1.2%) |
| **B1b (스파인 이벤트)** | **7,334** | **2,022 (−47%)** |

B1b 의 Valid AUC 0.8546 은 **양성이 절반뿐인 다른 라벨로 잰 값**이다. A0 의
0.8530 과 나란히 놓으면 서로 다른 문제를 푼 두 모델을 비교하는 셈이 된다.

**올바른 질문**: "불완전한 라벨로 학습한 모델이 *실제* 부도를 얼마나 맞히는가"
→ **학습은 변종 라벨로, 평가는 정답 라벨(현행 `budo_events` 기준)로** 한다.

### 교차 평가 결과 (시드 3회)

| 변종 | 학습 양성 | spw | 정답라벨 Valid AUC | σ | vs A0c132 (0.8530) | 판정 |
|---|---:|---:|---:|---:|---:|---|
| B1 | 5,473 | 105.29 | 0.8548 | 0.0027 | +0.0018 (1.3σ) | 차이 없음 |
| **B1b** | 4,642 | 123.96 | **0.8490** | 0.0018 | **−0.0040 (2.9σ)** | **확정 — 성능 하락** |

**B1b 판정**: 부도 이벤트 **623건 / 578사**를 놓치면 실제 부도 예측력이
**−0.0040 (2.9σ)** 떨어진다. STAGE 3 의 "부도 이벤트를 스파인이 아니라
`budo_events.csv` 원천에서 가져온다" 는 수정이 **정당했음을 실증**한다.

부도가 나면 여신이 정리되어 OBV 레코드가 사라지므로, 부도월이 스파인 밖에 있는
경우가 다수다. 스파인 안만 보면 그 기업들이 학습에서 통째로 사라진다.

**측정상 유의점**: B1 은 행 복제 때문에 Valid 가 312,773행(정답 312,334행보다
+439)이고 복제분이 대부분 양성이라, 일부 행이 두 번 계산된다. 가중이 약간
달라지지만 판정(차이 없음)은 바뀌지 않는다. B1b 는 312,334행 / 3,832 양성으로
정답과 정확히 일치해 비교가 깨끗하다.

## 2. ★ 부수 발견 — 노출도 20개를 빼면 오른다

| | 피처 | Valid 평균 | ΔAUC | σ배수 |
|---|---:|---:|---:|---:|
| A0 | 152 | 0.8437 | — | — |
| **A0c132** | 132 | **0.8530** | **+0.0093** | **6.6σ** |

`step6` 의 노출도 계열 20개(`exp_*`, `is_manufacturing` 등)를 제거하면
Valid AUC 가 **+0.0093 오른다.** 확정 판정 구간이다.

**"피처를 빼면 오른다"가 세 번째 사례다:**

| 제거 대상 | 개수 | ΔAUC | σ배수 |
|---|---:|---:|---:|
| `STD_INDS_MID2` (업종 중분류) | 1 | +0.0133 | 5σ |
| 노출도 계열 (`exp_*` 등) | 20 | +0.0093 | 6.6σ |
| sentinel 파생 | 36 | +0.0018 | 0.6σ (차이 없음) |

노출도가 해로운 이유는 아직 확인하지 않았다. 후보:
- `exp_fx_dbt` 는 (d) 부분오염이다 (분자 AC12 가 연 단위 = 누수). B6 교정 후
  재측정하면 달라질 수 있다.
- 대부분 JEMU 비율의 재조합이라 원변수와 중복이다 (이진 플래그와 같은 구조).

→ **B6 교정 후 노출도를 다시 넣어 비교하는 것이 다음 과제다.**

### B4 / B6 구현 방식

`step1`/`step2` 를 재실행하지 않고 **패널의 해당 컬럼만 원천에서 월 단위
backward as-of 로 다시 만들어 교체**한다. A1/A2 에서 쓴 메모리 조인과 같은
경로이며, 변화가 그 컬럼들로 정확히 격리된다. 조인마다 `assert len == n_before`.

- **B6**: 이월 상한 12개월, `AC12_STALE_MONTHS`(BASE_YM − BAS_YM) 파생 추가,
  `HAS_AC12_YN` 시점정합화, `exp_fx_dbt` 재계산으로 (d) 부분오염 해소
- **B4**: `BASE_YM` 이전(같은 달 포함) 발생 건만 세어
  `CRIF12_EVENT_CNT` / `_RSN_AM_SUM` / `_OVD_AM_SUM` / `_WORST_RSNC` 생성
