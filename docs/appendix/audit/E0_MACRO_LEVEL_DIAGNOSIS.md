실행일: 2026-08-31 · 재현: `python -m eda_pipeline.step35_macro_level_diagnosis`

## 0. 왜 이걸 재는가

D축 결과(`D_AXIS_RESULT.md` §5)에서 거시 **차분** 지표의 부호가 Train 과 Valid
사이에서 뒤집혔다 (`base_rate_diff12` Train +0.904 / Valid −0.909).
차분은 "금리가 **오르고 있는가**"를 재는데, 부도는 "금리가 **높은 상태가**
**얼마나 오래 지속됐는가**"에 반응한다는 가설이 남았다. 수준·누적 변수의
부호 안정성만 사전 점검한다. **모델 학습은 하지 않는다.**

### 산출 방식

- 종속 계열: 월별 **12개월 선행 부도율**(%) = `IS_BUDO_12M` 의 `BASE_YM` 별 평균.
  D축 §5-1 과 동일하다.
- Train = `BASE_YM < 202310` (33개월), Valid = `>= 202401` (17개월). Dev 3개월은 양쪽 어디에도 넣지 않았다 (D축 §5-1 과 동일).
- 상관은 Pearson. 결측은 쌍 단위로 제외한다.

### ★ 읽을 때의 주의 — 수준과 차분은 공표 시차가 다르다

지시대로 수준값은 `model_input_monthly.csv`(원천 레벨)에서 가져왔다. 이 파일은
**공표 시차가 적용되기 전** 상태다. 반면 비교 대상인 차분 지표는
`model_input_monthly_cleaned.csv` 라 `impute_data` Phase 1 의 지표군별 시차가
이미 걸려 있다 (Group A 0개월 / B +1 / C +2). `base_rate` 는 Group C 이므로
**수준은 차분보다 2개월 앞선 값**이다.

이 진단의 목적은 부호의 **방향**이지 시점 정합이 아니므로 그대로 두었다.
다만 여기서 고른 변수를 실제 모델에 넣을 때는 **반드시 같은 공표 시차를**
**적용해야 한다.** 적용하지 않으면 시점 누수다.

### 이 표의 한계 — 판단 전에 반드시 감안할 것

- 표본이 전반 17개월 / 후반 16개월뿐이다. n=17 에서 상관계수의
  표준오차는 대략 0.25 다. 부호가 같아도 '안정적' 이라고 단정할 수 없고,
  부호가 달라도 우연일 수 있다.
- 두 구간은 서로 다른 국면이다. 전반은 저금리·완화 국면,
  후반은 급격한 긴축 국면이다. 부호 일치는 '두 국면을 모두 통과했다' 는
  뜻이라 의미가 있지만, 국면이 둘뿐이라 세 번째 국면(완화 전환)에서도
  유지된다는 보장은 없다. 실제로 Valid 가 그 세 번째 국면이다.
- 월별 시계열은 자기상관이 강해 유효 표본이 명목 개월 수보다 작다.

→ **이 표는 후보를 좁히는 데만 쓰고, 최종 판정은 별도 홀드아웃으로 한다.**

## E0-4. ★ E0-3 이 선별 도구로 작동하는가 — 방법 자체의 점검

**이 절은 변수 선별에 쓰지 않는다.** E0-3(Train 내부 안정성)이 실제로
'Valid 에서도 부호가 유지될 변수' 를 골라내는지, **선별 도구의 성능**만
사후 확인한다. 여기 나오는 Valid 결과를 보고 변수를 고르면 그 순간
홀드아웃 오염이다. Valid 부호는 D축에서 이미 공개된 정보라 새로 열어 본
것은 없지만, **용도를 구분하지 않으면 같은 잘못이 된다.**

**E0-3 에서 '일치' 로 통과한 7개 중 Valid 에서도 부호가 유지된 것은 3개다.**

- 살아남은 것: `CPI_core`, `BSI_mfg_biz`, `BSI_mfg_biz_yoy`
- 뒤집힌 것: `base_rate`, `base_rate_diff12`, `cum_tightening_24m`, `rate_level_vs_5y_avg`

### 이것이 뜻하는 바

Train 내부에서 두 국면(전반 저금리·완화 / 후반 급긴축)을 모두 통과한 금리
계열이 세 번째 국면(완화 전환)에서 무너졌다. **Train 내부 안정성은 국면
전환에 대한 안정성을 보장하지 못한다.** Train 두 구간이 모두 '금리가
올라가거나 높은' 국면이었기 때문이다 — 서로 다른 구간처럼 보이지만
부도 대비 금리의 방향은 같았다.

**E0-3 를 단독 선별 기준으로 쓰면 안 된다는 뜻이다.** 통과한 변수 중
실제로 살아남은 것은 심리지수 계열뿐이고, 그것은 E0-3 를 돌리기 전에
D축 §5-4 에서 이미 나온 단서다. 즉 E0-3 가 새로 알려 준 것이 없다.
