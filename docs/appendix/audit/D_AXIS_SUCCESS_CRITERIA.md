## [게이트 3] 실질 가치 — 캘리브레이션이 핵심 판정 기준

> **AUC 로 거시를 판정하지 않는다.**
> AUC 는 동일 시점 내 순위 지표이고, 거시는 모든 기업을 같은 방향으로 이동시켜
> 순위를 거의 바꾸지 않는다.

| ID | 검증 항목 |
|----|-----------|
| G3-1 | Valid AUC : D0 대비 **-0.003 이내 유지** ← "오르면 좋고, 안 떨어지면 성공" |
| G3-2 | 월별 예측평균PD vs 실제부도율 **상관계수 : D0 대비 상승** ★핵심 |
| G3-3 | 시점별 예측부도건수 **MAPE : D0 대비 하락** ★핵심 |
| G3-4 | **Brier Score : D0 대비 하락** |
| G3-5 | 캘리브레이션 곡선(예측PD 10분위별 실제부도율)이 대각선에 더 근접 |

### 확률 보정 필수
- `scale_pos_weight` 를 쓰면 예측 PD 가 실제 부도율보다 과대추정된다.
- G3-2~G3-5 산출 **전에** prior correction 또는 Platt scaling 을 적용한다.
- 보정 방식과 **보정 전후 평균 PD 를 함께 기록**한다.
- 보정은 **Train 구간에서만 학습해 Valid 에 적용**한다.

### 측정 근거 (거시가 설명해야 할 구간)

# 개정 이력

## R1 (2026-08-31) — G1-5 재기술. 기준 설정 오류의 정정.

**적용 시점**: 게이트 1 1차 실행 후, D축(D0~D5) 학습 **실행 전**.
D0~D5 는 이 개정 이전에 단 한 번도 학습하지 않았다. 성능 결과를 본 뒤의
기준 완화가 아니다.

### 구 문장 (원문 보존)

```
G1-5  상호작용항 8종 전부 BASE_YM 내 분산 > 0
```

### 신 문장

```
G1-5   거시 충격 항이 0 이 아닌 달에 한해, 상호작용항의 기업 간 분산 > 0
       (충격 항 == 0 인 달은 판정 대상에서 제외하고 건수만 기록)

G1-5b  각 상호작용항의 "충격 0 인 달" 개수와 해당 행 비율을 반드시 기록
```

### 개정 사유

G1-5 를 만들 때 밝힌 근거는 **"분산이 0이면 시점 더미로 퇴화한 것"** 이었고,
검증하려던 것은 **"충격이 존재할 때 기업마다 다르게 반응하는가"** 였다.
그런데 실제로 쓴 문장은 "전 월에서 분산 > 0" 이어서, **충격 자체가 0 인 달까지
실패로 잡는 기준**이 되었다. 의도와 문장이 어긋난 것이므로 문장을 의도에 맞춘다.

금리 동결 구간에서 `base_rate_diff12` = 0 이면 곱셈 결과가 전 기업 0 이 되는 것은
설계대로의 정상 동작이다. 노출도(`exp_rate`, std 0.22)는 살아 있고 충격이 없을
뿐이다. **이는 시점 더미로의 퇴화와 정반대 현상이다.**

합성 난수는 정확히 0 을 만들지 못해 이 구간을 53/53 으로 통과시켰다.
실데이터로 바꾼 뒤에야 드러난 것이므로, 발견 자체가 정상적인 검증 결과다.

**원인 B(202101~03 패널 warm-up 3개월)도 판정 대상에서 제외한다.**
AA17 은 분기 wide 포맷이라 2021 Q1 의 `AVAIL = 202104`,
JEMU 는 202012 결산 + `PUB_LAG_MONTHS=4` → `AVAIL = 202104` 다.
누수를 막는 정상 동작이며 거시 결합과 무관하다.
영향은 Train 46,448행(4.90%) / 양성 314건이고 **Valid 는 0행**이다.

### 채택하지 않은 대안 — 금리 상호작용항 재정의

`base_rate_diff12` 를 `corporate_bond_3y_AA_diff12` 등으로 바꾸면 "충격 0 인 달"
이 사라져 구 G1-5 도 통과한다. **채택하지 않는다.**
동결 구간에서 0 이 되는 것은 데이터의 사실이지 결함이 아니며, 지표를 바꿔 0 을
없애는 것은 *"기준을 통과시키기 위한 설계 변경"* 이 되어 결과에 맞춰 기준을
고치는 것과 같은 문제를 낳는다. 금리 경로가 실제로 비어 있다는 것이 확인에서
드러나면, 그때 근거를 갖고 재설계한다.

# D축 해석 규칙 (R1 과 함께 확정)

기준 통과 여부와 별개로, 아래는 D축 결과 해석에 **결정적**이다.
D축 결과표와 STAGE 7 보고서에 그대로 명시한다.

> `rate_shock_x_leverage` 는 정책금리 동결 구간에서 구조적으로 0 이 된다.
> 이 항의 gain 이 낮게 나오더라도 '금리 경로가 무의미하다'는 뜻이 아니라
> '분석 기간의 절반이 금리 변동이 없는 구간'이라는 뜻이다.

실측: **Valid 312,334행 중 53.1%(165,967행)에서 `rate_shock_x_leverage` = 0.**

**각 상호작용항의 "0 비율" 을 D축 결과표에 컬럼으로 추가한다.**
gain 은 0 비율과 함께 읽어야 해석이 가능하다.
