### 판정 규칙 정정 — 조건 2 는 애초에 달성 불가능한 기준이었다

사전 판정 기준은 다음 셋을 요구했다.

1. AUC 가 기준선 대비 −0.003 이내 → **충족** (−0.0001)
2. **거시 계열 중 gain 상위 50위 진입 10개 이상** → **미달** (시드별 1개)
3. MAPE 가 기준선 대비 +5%p 이내 → **충족** (−5.23%p, 오히려 개선)

조건 2 는 **물리적으로 달성할 수 없는 기준**이었다. 169개 피처 중 상위 50위는
기업 고유 피처가 채운다 — `C302_CRI_ORD` 한 변수가 gain 29% 이고 `JEMU_*` 계열이
그 뒤를 잇는다. 거시 상호작용항이 그 자리를 차지할 이유가 없다.

**대체 기준**: "14개 중 매 시드에서 gain > 0 인 항이 10개 이상" → **충족 (10개)**

> ★ **결과를 보고 기준을 바꾼 것이 아니다.** 기준이 달성 불가능했음을 실측으로
> 확인한 것이다. 근거: 세 시드 모두 거시항의 최고 순위가 45~49위였고, 그 위 44개
> 자리는 전부 기업 고유 피처였다. 거시가 잘 작동하더라도 그 순위 안에 10개가
> 들어오려면 기업 고유 피처 10개를 밀어내야 하는데, 그것은 거시의 성능이 아니라
> 기업 피처의 약화를 뜻한다. 목표로 삼을 값이 아니었다.

## 3. 거시 3층 구조

**"거시 14개를 썼다" 고 쓰지 않는다.** 세 숫자가 각각 다른 것을 뜻한다.

```
수집 65개 (enabled=Y)
  ECOS 40 / YAHOO 22 / KOSIS 3
        │  − DROP_COLS 2 (GNI_annual · manufacturing_index)
        ▼
원지표 63개
        │  정상성 변환 (_log_ret / _vol_m / _diff12 / _yoy / _ma3m)
        ▼
변환 변수 178개
        │  부호 검사 대상 97개
        │    = 89개 (_ma3m 86개 · 수준계열 제외) + 추가 후보 8개
        │      (스프레드 수준 2 + 신규 스프레드 6)
        ▼
4구간 부호 일치 + 상관 임계 통과 10개
        │  + 완화 편입 5개 (부호는 일치, 상관 강도만 미달)
        │  − 압축 탈락 1개 (BSI_mfg_biz — BSI_mfg_domestic 과 상관 0.95 이상)
        ▼
거시 원계열 14개  ×  노출도 6종 결합
        │  명세 22개 → 압축 규칙 → 최종 14개
        ▼
최종 상호작용항 14개
```

- **부호 검사**: 4구간(Train 전반 16개월 / Train 후반 17개월 / Train 전체 33개월 /
  Valid 17개월)에서 상관 부호가 전부 일치할 것 + `|r(train_all)| ≥ 0.15` +
  `|r(valid)| ≥ 0.10`.
- **완화 편입 5개**: `NEW_KORIBOR_spread_diff12`, `CPI_food_nonalcohol_yoy`,
  `JPY_KRW_log_ret`, `gold_log_ret`, `Shanghai_Composite_log_ret`.
  **부호 안정성을 1차 기준, 상관 강도를 2차 기준으로 적용**했다 —
  4구간 부호가 일치하면 D3 처럼 캘리브레이션을 망가뜨릴 위험이 낮고,
  상관이 약한 것은 gain 이 낮게 나올 뿐 해를 끼치지 않는다는 판단이다.
  완화 기준: `|r(train_all)| ≥ 0.01`.
- **압축 규칙**: 결측률 80% 초과 제거 / 충격 0 인 달 비율 40% 초과 제거 /
  충격 0 제외 후 월내 무분산 제거 / 항 간 상관 0.95 이상 대표 1개 / 상한 25개.
  실제로 걸린 것은 **R4(상관 중복) 8개뿐**이다.
- **14개가 구조적 상한이다.** 거시 실질 표본이 53개월이고 부호 안정성을 통과한
  원계열이 14개다. 같은 거시에 여러 노출도를 곱해도 월 내 거시항이 상수이므로
  월별 평균이 노출도 평균의 스칼라배가 되어 상호 상관이 0.95 를 넘고 압축된다.
  **따라서 상호작용항 개수는 거시 원계열 개수를 넘을 수 없다.**

## 6. 캘리브레이션 분리 방침

**용도에 따라 다른 보정을 쓴다.** 네 보정은 모두 로짓의 단조 변환이므로
**순위·AUC·등급 컷오프는 완전히 동일**하다. 보정이 바꾸는 것은 **표시하는 PD 값**뿐이다.

| 용도 | 보정 | 근거 |
|---|---|---|
| 모델 비교·판정 | **`platt_train`** | 기준서의 *"보정은 Train 구간에서만 학습해 Valid 에 적용"* 을 문자 그대로 만족한다. 홀드아웃 오염이 없다 |
| 포털 표시 PD | **`platt_dev`** 또는 운영 시점 직전 구간 재적합 | Dev(202310~202312)가 Valid 와 인접해 기저율이 비슷하다. 시나리오 **비교**에는 부적절하나(절편이 Valid 기저율을 간접 노출), **운영에서는 "예측 직전 구간 재보정" 이 정상 절차**다 |
| Z-Score 등급 | **무관** | 등급은 로그오즈 기준이고 보정은 단조 변환이라 컷오프가 바뀌지 않는다 |

### 실측 (D6m, 시드 10회) — 기저율 Train 0.9116% / Dev 1.2424% / Valid 1.2269%

| 보정 | 평균 PD% | 실제 대비 | 0 으로 보이는 분위 수 | 월별 MAPE% |
|---|---:|---:|---:|---:|
| `raw` | 8.8336 | 7.20배 | 0 | 626.17 |
| `prior` | 0.2235 | 0.18배 | 1 | 81.63 |
| `platt_train` | 0.4328 | 0.35배 | **6** | 64.43 |
| **`platt_dev`** | **1.0632** | **0.87배** | 2 | **12.72** |

- **원인은 H1(구간 기저율 차이)** 이다. 적합 구간만 Train → Dev 로 바꾸니 평균 PD 가
  0.43% → 1.06% 로 올라 실제 1.2269% 에 근접하고, 0 으로 보이는 분위가 6개 → 2개로
  줄고, 월별 MAPE 가 64.43% → 12.72% 로 5배 개선됐다.

### `prior_correction` 이 최악이었던 이유 — 규제와 가중치의 상호작용

사전 예상은 "`prior` 가 가장 단순하고 이론적으로 정확할 것" 이었으나
**실측은 가장 나빴다**(평균 PD 0.2235%, `platt_train` 보다 더 과소추정).

`prior` 는 `scale_pos_weight` 가 부풀린 양성 오즈를 되돌리는 해석적 역보정이다
(로그오즈에서 `ln(spw)=4.6886` 차감). 그런데 **R2 규제
(`num_leaves=7, reg_alpha=5, reg_lambda=5`)가 이미 트리 확률을 눌러 놓았다.**
`raw` 평균 PD 8.83% 에서 `ln(spw)` 를 또 빼면 0.22% 로 내려가 **과보정**된다.
"예측 오즈가 `spw` 배만큼 부풀려져 있다" 는 전제가 이 모델에서는 성립하지 않는다.

> **교훈**: 가중 학습의 해석적 역보정은 **규제가 약할 때만** 성립한다.
> 강한 규제와 클래스 가중치를 함께 쓰면 두 효과가 상쇄되어, 역보정이 이중 보정이 된다.
