## 1. PD-LAG 차트의 우측절단(right-censoring) 착시 보정

사용자가 PD-LAG 차트를 보고 "ERM 예측이 실제 부도율보다 너무 높게 나와 모델 성능이 안 좋아 보인다"고 지적. 원인을 데이터로 직접 확인한 결과 두 가지가 섞여 있었음:

- **우측절단(기계적 왜곡)**: `실제`(시장 실질 부도율)는 "해당 월 기준 향후 12개월 내 부도 여부"(`IS_BUDO_12M`)의 평균인데, DB의 최신월(26.06)에 가까운 최근월일수록 12개월 관측 창이 아직 다 지나지 않아 `실제`가 인위적으로 0에 수렴함 (25.07 0.95% → 26.06 0.00%). 모델이 못 맞춘 게 아니라 "아직 결과가 안 나온" 구간이 강제로 낮게 표시되는 것.
- **캘리브레이션 격차(별도 이슈, 이번엔 미조치)**: 절단 영향이 없는 과거 구간에서도 ERM 평균 예측 확률이 실제 발생률보다 6~9배 높게 나옴 — LightGBM 원시 확률이 실제 발생빈도와 1:1로 보정되지 않은 전형적 현상(변별력과는 별개). 사용자 확인 하에 이번 조치 범위에서는 제외.

### 조치 (우측절단만 보정)
- `backend/routers/dashboard.py`의 `/api/dashboard/trend`: 각 월의 12개월 관측 창이 DB 최신월을 넘어서면(`month + 12 > max_ym`) `실제`를 `null`로 반환하고 `censored: true` 플래그 추가.
- `frontend/src/pages/GlobalDashboard.tsx`: 절단 구간을 회색 음영(`ReferenceArea`)으로 표시, 라인은 `connectNulls={false}`로 끊어서 그림, 커스텀 툴팁(`TrendTooltip`)에 "아직 12개월 관측이 끝나지 않아 집계 불가" 안내 문구 추가, 차트 하단에 절단 구간 안내 캡션 추가.

## 2. 부도 예측 성공/실패 벤다이어그램 (신규)

사용자가 "실제 부도가 발생하기 전에 예측한 시점", "우리 지표 vs 기존 내부 지표로 예측 성공/놓친 업체 수를 벤다이어그램으로" 요청.

### 방법론
- 은행 실제 내부 조기경보등급(`OBV_ELYWRN_OBV_GRD_DSC`, 값 A/B — 모델의 실제 카테고리형 피처이기도 함)을 "기존 지표"로 사용. 이는 조작된 근사치가 아니라 원천 데이터에 실재하는 진짜 내부 등급.
- 각 실제 부도 기업(`IS_BUDO_12M=1` 발생 이력 보유)에 대해 "부도 시점"을 그 12개월 관측 창이 마지막으로 부도를 포함하는 월(`default_pivot`)로 근사.
- `default_pivot` 이전 시점에 ERM이 G4/G5로, 내부등급이 'B'로 각각 "먼저 경고"했는지 여부로 4분면(둘 다 포착 / ERM만 포착 / 내부만 포착 / 둘 다 놓침) 산출.

### 좌측절단(left-censoring) 함정 발견 및 보정
- 최초 계산 시 "둘 다 포착" 386개사의 평균 리드타임이 **음수(-2.7개월)**로 나와, 데이터를 다시 파고듦.
- 원인: 386개 중 313개사는 패널 관측이 시작되는 첫 행부터 이미 내부등급이 'B'였음 — 즉 "언제 내부가 위험을 감지했는지" 알 수 없는 좌측절단 케이스가 대다수를 차지해 평균을 왜곡시킴.
- 진짜 A→B 전환이 관측된 73개사만으로 재계산하니 **평균 +9.2개월**(ERM이 먼저 경고) — 기존 README의 6.8개월 수치와 방향이 같고 표본도 더 큼. 이 값을 채택하고, 제외된 313개사는 화면에 각주로 투명하게 명시.

### 조치
- 신규 엔드포인트 `GET /api/dashboard/prediction_comparison`: `{both, erm_only, internal_only, neither, total, lead_time: {avg_months, n, left_censored_excluded}}` 반환.
- 결과: **ERM만 포착 580 / 둘 다 포착 386 / 내부만 포착 0 / 둘 다 놓침 7** (전체 973개사, 내부등급 이력 보유 기준), **평균 리드타임 +9.2개월** (진짜 전환 관측된 73개사 기준).
- `GlobalDashboard.tsx`에 `PredictionVenn` 컴포넌트(2-set SVG 벤다이어그램: 사각형=전체 부도기업, 원 2개=ERM/내부 포착 집합, 사각형 안 원 밖=둘 다 놓침) + 리드타임 통계 카드 추가.

## 3. 검증

- 신규/수정 엔드포인트 curl 직접 호출로 값 확인 (`censored` 플래그, `prediction_comparison` 4분면 합계 정합성).
- `npx tsc --noEmit` 통과.
- **Playwright 신규 설치** (`frontend`에 devDependency로 추가 — 브라우저 바이너리는 로컬에 이미 캐시되어 있어 재다운로드 없이 즉시 사용 가능). `http://localhost:5173/global` 실 렌더링 스크린샷으로 벤다이어그램 및 PD-LAG 차트 정상 표시, 콘솔 에러 0건 확인.

## 4. 후속 과제 (미조치, 기록만)

- PD-LAG 차트의 캘리브레이션 격차(예측 확률이 실제 발생률보다 6~9배 높게 나오는 문제)는 이번 범위에서 제외. 필요 시 isotonic regression 등으로 표시용 확률을 보정하는 후속 작업 고려.
