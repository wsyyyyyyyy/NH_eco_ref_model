# 📖 데이터 명세서 (Data Dictionary)

본 명세서는 ECO Ref Model 파이프라인에 사용된 데이터의 컬럼 명세, 파생 변수, 외부 결합 데이터를 종합적으로 안내합니다. (VIF 다이어트를 통해 최종 선택된 80여 개의 핵심 Feature 위주로 요약되었습니다.)

---

## 1. 🔑 식별자 및 차주 기본 정보 (Base Features)
| 물리 컬럼명 (Column) | 한글 설명 (Description) | 출처 / 비고 |
| :--- | :--- | :--- |
| `V_BZNO` | 가상 사업자등록번호 | 차주 식별용 Primary Key |
| `BASE_YM` | 기준 연월 (YYYYMM) | 시계열/패널 데이터 기준 키 |
| `COPR_OPNP_C` | 기업공개구분 | 상장/외감/비외감 등 법인 성격 구분 |
| `BZSCAL_C` | 기업규모코드 | **모델 타겟팅 기준** (해당 값이 `4.0`인 차주만 필터링) |
| `STD_INDS_CFC` | 표준산업분류코드 | 국세청 표준산업분류 연계표를 활용해 한글 업종명으로 맵핑하여 사용 |

---

## 2. 🎯 타겟 및 신규 파생 변수 (Target & Derived Features)
*데이터 전처리 과정(`step5_panel_prep.py` 등)에서 분석 기획에 따라 새롭게 생성(엔지니어링)된 핵심 피처입니다.*

| 물리 컬럼명 (Column) | 한글 설명 (Description) | 생성 방식 / 비고 |
| :--- | :--- | :--- |
| **`IS_BUDO_12M`** | **향후 12개월 내 부도 발생 여부** | **🌟 최종 예측 타겟 (Y)** <br> 특정 `기준 연월(BASE_YM)`로부터 실제 부도일자(`DSH_DT`)까지의 기간을 계산하여, 12개월(Time-to-Default) 이내면 `1`, 아니면 `0`으로 산출 |
| `BUSINESS_AGE` | 업력 (단위: 년) | `기준 연월(BASE_YM)` - `설립일자(ETB_DT)`로 계산. 모델의 SHAP Value 상위권에 랭크된 핵심 변수 |
| `IS_MISSING_KIS` | KIS 신용평점 결측 여부 | 점수가 없는 영세 기업 특성을 잡기 위해 결측치를 `-1` 또는 특정 상수로 대치하여 파생된 리스크 시그널 |

---

## 3. 🌍 외부 데이터 결합 (Macro-Economic Features)
*거시 경제 사이클에 따른 기업의 부도 리스크 민감도를 반영하기 위해 외부에서 추가로 결합(Join)한 시계열 지표입니다.*

| 물리 컬럼명 (Column) | 한글 설명 (Description) | 출처 / 비고 |
| :--- | :--- | :--- |
| `KOSPI` | 코스피 종가 | 경제 전반의 활력 지표 |
| `EUR_KRW` | 원/유로 환율 | 환율 변동에 민감한 수입/수출 기업 리스크 반영 (SHAP 주요 변수) |
| `CPI` | 소비자물가지수 (Inflation) | 원자재 및 운영비용 상승 압력 지표 |
| `INTR_RATE` | 기준 금리 | 이자 상환 부담 및 자금 조달 비용 압박 지표 |
