# [Phase 2] 모델 학습 및 SHAP 중요도 기반 요인 분석 (Step 07 ~ 09)

본 보고서는 중소기업(SME) 4.0 신용평가 모형의 **기계학습(LightGBM) 알고리즘 학습, SHAP 가치 기반 설명력 확보 및 다중공선성(VIF) 필터링/Z-Score 튜닝** 과정에 대한 요약 보고서입니다. 모형의 설계 논리와 리스크 관리 관점의 인사이트 중심으로 구성되었습니다.

---

## 🤖 1. LightGBM 모형 학습 및 설계 (Step 07)

### 1.1 LightGBM 선택 사유
중소기업 신용 평가는 대기업에 비해 데이터 분포의 비선형성이 매우 강하고 결측치가 다양하게 발생합니다. **LightGBM**은 대용량 데이터의 분산 학습 속도가 빠를 뿐만 아니라, 의사결정 나무(Decision Tree) 기반으로 변수 간 상호작용(Interaction)과 비선형 관계를 매우 효과적으로 학습합니다.

### 1.2 모형의 기본 구조
* **Target (y)**: 12개월 이내 부도 여부 (`0` 또는 `1`)
* **Features (X)**: 기업 재무 비율 (안정성, 수익성, 활동성 등 50여 개) + NICE 신용 평점 + 거시경제 변수 (기준금리, 환율 등)

## 🔍 2. SHAP (SHapley Additive exPlanations) 요인 분석 (Step 08)

머신러닝 모형의 고질적인 단점인 **'Black Box(설명 불가능성)'** 문제를 극복하고 금융 감독 기관 및 내부 심사역의 신뢰를 확보하기 위해, 협조적 게임이론 기반의 **SHAP Value**를 산출하여 모델을 시각화하였습니다.

### 2.1 글로벌 변수 중요도 (Global Feature Importance)
전체 차주에 대해 어떤 변수가 부도 예측에 가장 큰 영향력을 미쳤는지 분석하였습니다. 상위 50개 주요 변수의 SHAP 가치를 정렬하여 시각화하였습니다.

![SHAP Summary Plot](images/shap_summary_top50.png)

### 2.2 SHAP 의존성 분석 (Dependence Plot)
특정 주요 변수(예: 매출액 증가율, 차입금 의존도)의 수치 변화에 따라 부도 위험 가중치가 비선형적으로 어떻게 변동하는지 미시 분석을 수행하였습니다.
* **비즈니스 인사이트**: 차입금 의존도가 특정 임계점(Threshold)을 넘어서는 순간 부도 확률(SHAP Value)이 급격히 스파이크를 일으키는 임계 구간을 식별하여, 심사 한도 설정 시 중요한 가이드라인을 제공합니다.

![SHAP Dependence Plot](images/shap_dependence.png)

## 🛠️ 3. 다중공선성(VIF) 필터링 및 Z-Score 모형 튜닝 (Step 09)

### 3.1 다중공선성(VIF) 리스크 해결
재무 변수들(예: 자산총계, 매출액, 부채총계 등)은 서로 강한 양의 상관관계를 갖는 경우가 많아, 모형의 안정성을 해치고 중요 변수의 왜곡을 초래합니다. 
이를 해결하기 위해 **분산팽창요인(VIF: Variance Inflation Factor)**을 단계적으로 측정하여, **VIF가 10 이상인 유사/다중공선성 변수를 자동으로 드롭**하는 필터링 알고리즘을 도입하였습니다.

### 3.2 Z-Score 아웃라이어 조절을 통한 모형 튜닝
* **목적**: 경기 변동성 극대화 시기나 영세 중소기업의 재무 수치 극단치(Outlier)로 인해 예측 모형이 왜곡되는 현상을 방지합니다.
* **조치**: 각 변수별 Z-Score를 산출하여 극단치 영역을 Winsozation(하한 1%, 상한 99%) 처리함으로써 모형의 일반화 성능(Robustness)을 비약적으로 개선하였습니다.
* **결과**: 다중공선성을 제거하고 안정화된 최적 변수셋을 확정하여 최종 LightGBM 모형(V3)의 기초 뼈대를 구축하였습니다.
