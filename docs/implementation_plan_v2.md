# 부도 예측 모델 고도화 계획 (Walkthrough v2: 실무 적용성 및 방향성 검증)

제안해주신 5단계 접근법은 단순한 지표(AUC) 개선을 넘어 **실제 비즈니스 투입 시의 안정성, 직관성, 그리고 경제적 효익**을 검증하는 매우 훌륭하고 정석적인 전략입니다. 현재 완성된 1차 풀모델(ROC AUC 0.9011)을 바탕으로, VIF 다이어트와는 별개의 **'해석 및 실무 검증 중심의 Walkthrough v2'** 트랙을 진행하겠습니다.

## ❓ Open Questions (사전 확인 사항)

> [!NOTE]
> **KIS_SCORE 결측치 처리 관련**
> 전처리 코드(`step5_panel_prep.py`)를 확인해 본 결과, `CG01_KIS_SCORE` 자체의 완전 결측치(NaN)는 전체의 **중간값(Median)**으로 대체되었습니다. 다만, 원본 데이터 자체에 점수가 산출되지 않은 경우 이미 특정 값(예: 0, -1, 999 등)으로 들어와 있었거나, `CRIF_CRDBD_RSNC`(신용불량 사유코드) 같은 범주형/상태 코드가 결측일 때 제가 `-1`로 채운 부분이 상위 변수로 작용했을 수 있습니다.
> 
> *따라서 이번 3단계 분석 시, KIS_SCORE의 특정 특이값(점수 없음) 그룹과 정상 점수 그룹, 그리고 `CRIF_...` 변수들의 결측(-1) 그룹을 세밀하게 나누어 "정보 부재"가 주는 효과를 명확히 분리하여 보고하겠습니다.*

> [!IMPORTANT]
> **비용 함수(Cost Function) 가중치 설정**
> 1단계 최적 Threshold 산출 시 사용할 **"오경보(FP) 비용 vs 실제 부도 미탐(FN) 비용"의 비율**을 대략적으로 어떻게 잡는 것이 비즈니스 상황에 맞을지 의견을 여쭙고 싶습니다.
> *(의견이 없으시다면 통상적인 보수적 은행 기준인 FN 비용 = FP 비용의 10배~20배 로 가설을 세워 진행하겠습니다.)*

## 🛠 Proposed Changes (진행 단계)

### 1단계: Threshold 최적화 및 비용 기반 평가 (Cost-based Evaluation)
*   **Precision-Recall Curve 산출**: 확률별 Precision과 Recall의 변화를 시각화합니다.
*   **최적점 도출**: 
    1. **F1-Max**: Precision과 Recall의 조화평균이 최대가 되는 점
    2. **F2-Max**: 부도 적발(Recall)에 2배의 가중치를 두었을 때의 최적점
    3. **비용 최적화(Cost-Optimal)**: 오탐 비용과 미탐 비용을 반영한 비즈니스 관점의 최적 Threshold 산출

### 2단계: SHAP Dependence Plot을 통한 방향성 검증 (Business Intuition Check)
*   Top 10~15개 핵심 수치형 변수(`BUSINESS_AGE`, 주요 재무지표, `EUR_KRW` 환율 등)에 대해 **SHAP Dependence Plot**을 생성합니다.
*   값이 커질 때 부도 위험이 커지는지(양의 방향), 작아지는지(음의 방향) 시각화하여, **모델이 비즈니스 직관(Domain Knowledge)과 일치하는 논리를 학습했는지, 혹은 Data Leakage나 전처리 오류로 인한 기형적 패턴이 없는지** 검증합니다.

### 3단계: 결측치/정보 부재(-1, 특이값)의 영향도 분리
*   `CRIF_CRDBD_RSNC`(-1 처리), `CG01_KIS_SCORE` 등의 주요 변수에서 특정 "정보 없음" 그룹과 "정상 값" 그룹을 분리합니다.
*   두 그룹 간의 실제 부도율 차이와 SHAP 기여도 차이를 비교하여, **"정보가 없다는 사실 자체"를 리스크로 판단한 것인지, 값 자체의 변별력인지를 규명**합니다.

### 4단계: 시간 기반 교차 검증 (Time-Series Cross Validation)
*   현재의 단순 분할(23년 Train, 24년 Valid)을 넘어, 2023년 데이터를 분기별 혹은 반기별로 쪼개어 **Rolling Window CV (Walk-Forward Validation)**를 수행합니다.
*   시점이 이동함에 따라 모델의 ROC AUC 성능과 SHAP 중요도 순위가 요동치지 않고 안정적으로 유지되는지(Stability) 점검합니다.

## ✅ Verification Plan

*   **실무 수용성**: Precision 0.15 상황에서 Threshold 튜닝을 통해 실무자가 수용 가능한 Precision(예: 오경보율 감소) 수준을 어디까지 타협할 수 있는지 대안을 제시합니다.
*   **모델 신뢰도 확보**: 방향성 검증(2단계)과 결측치 분석(3단계)의 결과는 [Walkthrough v2] 보고서에 그래프와 함께 수록하여, "모델이 왜 그런 결정을 내렸는지"에 대한 완벽한 해석을 제공합니다.
