# [Step 23] 공유용 정적 Mockup HTML 제작

> **작성일**: 2026-07-03
> **기준**: 팀원 공유를 위해 백엔드/프론트엔드 풀스택 실행 없이 열어볼 수 있는 단일 파일 목업 요청

---

## 1. 배경

실제 포털(FastAPI + DuckDB + React/Vite)은 팀원에게 공유하려면 백엔드 서버 구동, `portal.duckdb` 확보, `npm install` 등 셋업이 필요해 가볍게 공유하기 어렵다는 피드백을 받음. "실제 화면과 같고, 데이터는 일부만, 동작하는 수준으로" 볼 수 있는 정적 목업을 요청받아 `mockup.html` 단일 파일로 제작.

## 2. 구현

- **`mockup.html`** (리포지토리 루트, 약 1,200줄, 외부 런타임 의존성 없음. Pretendard 폰트만 CDN, 실패 시 시스템 폰트로 자연 대체):
  - `frontend/src/index.css`의 디자인 토큰(색상 변수, `.card`/`.badge`/`.grid-2` 등 유틸리티 클래스)을 그대로 이식해 실제 화면과 동일한 룩앤필 유지.
  - 로그인 → 사이드바 4메뉴(글로벌 뱅크 뷰 / 지점 대시보드 / 모델 모니터링 / 매크로 시뮬레이션) + 차주 상세를 vanilla JS SPA 방식(`showPage()`)으로 전환.
  - **샘플 데이터**: 시드 고정 PRNG(`mulberry32`)로 차주 220개사를 실제 등급 분포(G1 19%/G2 39%/G3 24%/G4 9%/G5 9%)에 맞춰 생성. NICE/KIS 등급은 확률의 백분위 순위 기반으로 매겨 실제 화면처럼 등급이 고르게 분산되도록 조정(초기 버전은 절대 확률 기준이라 대부분 AAA 근처로 몰리는 문제가 있어 재작업).
  - **차트**: Recharts 대신 의존성 없는 순수 SVG 헬퍼 함수(`lineChart`, `barChart`, `groupedBarChart`, `scatterChart`, `radarChart`, `areaChart`, `hBarChart`)를 직접 작성해 인터넷 연결 없이도 렌더링되도록 함.
  - **실제로 동작하는 인터랙션**: 지점 대시보드 검색/업종/NICE/ERM 등급 필터 + 3개 요약탭 + 페이지네이션(클라이언트 필터링), 차주 클릭 시 상세 페이지 이동(3개년 재무표/부도확률 추이/역량진단 레이더/SHAP 기여도/AI 팁 아코디언 — 차주별로 시드 기반 고유 값), 모델 모니터링의 PD 구간 막대 클릭 시 우측 차주 목록 갱신, 매크로 시뮬레이션의 5개 슬라이더 + 4개 역사적 위기 프리셋 + 4가지 뷰(막대/히트맵/3단 매트릭스/레이더) 실시간 재계산(`MacroSimulation.tsx`의 목업 모드 공식을 그대로 이식).
  - **부도 예측 성공/실패 벤다이어그램**은 가공하지 않고 Step 21~22에서 실측 검증한 실제 결과(ERM만 포착 580 / 둘 다 포착 386 / 내부만 0 / 둘 다 놓침 7, 평균 리드타임 +9.2개월)를 그대로 재현.

## 3. 검증

- Playwright로 로그인 → 5개 화면 전체 이동, 지점 대시보드 검색/필터, 차주 상세 진입, 모니터링 PD-Bin 클릭, 시뮬레이션 프리셋/슬라이더/탭 전환까지 조작 후 스크린샷 확인, 콘솔 에러 0건.
- 업종별 산점도 라벨이 버블과 겹치는 문제를 지그재그 오프셋(실제 앱의 `CustomScatterLabel`과 동일한 방식) 적용으로 수정.
